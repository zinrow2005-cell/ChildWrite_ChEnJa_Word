4. 系統會檢查 40 個入門國字是否都包含可讀取的逐筆路徑、筆畫數是否符合教材基準、是否有大量不同字共用同一路徑。資訊分為「網站內建」與「此裝置可用」，不會混淆。
5. 資料齊全且結構檢查通過後，可按 **產生國字離線網站 ZIP**。將新 ZIP 解壓後整包上傳 GitHub Pages，其他手機、平板無需各自匯入國字筆順。

## 完成度與限制

- 基礎 V1.26 ZIP **沒有內建真實 AnimCJK 40 字逐筆資料（0/40）**，但 40/40 國字空心字仍可離線描寫，舊版人工示意路徑仍只是「示意」。
- 如果原始檔本身缺少某些國字或筆畫數與基準不同，匯入結果會列出缺字，完整網站 ZIP 不會開放，避免冒充已完成。
- 從檔案取得筆畫路徑且通過程式檢驗，**不代表已與教育部國字標準字體筆順逐字人工核對**；尤其筆畫方向仍需人工對照。
- 產生完整 ZIP 時需從當前網站讀取本機靜態檔案，建議在 GitHub Pages（HTTPS）操作，而非直接以 file:// 開啟。
- 原始資料及開源字形須依 `THIRD_PARTY_NOTICES.md` 的 Arphic Public License 條款保留來源說明。請勿把測試用的模擬筆畫當成教材。
