V1.23 日文 92 字 GitHub Actions 自動打包

1. 先匯出舊版練字備份。
2. 解壓本 ZIP，將所有檔案連同 .github/ 與 scripts/ 一起上傳 GitHub 儲存庫。
3. GitHub 儲存庫 Settings → Pages → Source 選 GitHub Actions。
4. 在 Actions 頁面執行「小小練字樂園｜92字真實筆順與 GitHub Pages」。
5. 若成功，GitHub Pages 已部署含 92 字筆順版本，並可在該次 Actions 的 Artifacts 下載完整 ZIP。
6. 若建置失敗，不代表 ZIP 已有 92 字；請查看來源下載／結構檢查的錯誤，勿以模擬資料替代。

基礎 ZIP 僅內建「あ」，並非 92/92 已完成。完整筆順須從真實開源來源成功取得後才成立。
